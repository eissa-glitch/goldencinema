# خطة: نظام اشتراكات وباقات

## نظرة عامة
نظام اشتراكات بـ **3 باقات** (مثلاً: مجاني / فضي / ذهبي)، الأدمن يفعّل/يوقف اشتراك كل عضو يدوياً من لوحة التحكم. الباقات تتحكم في:
- **الوصول للأفلام والتفاصيل** (صفحة تفاصيل الفيلم محمية للمشتركين)
- **حد أقصى لعدد المشاهدات شهرياً** لكل باقة

## قاعدة البيانات (Migration)

### 1. جدول `subscription_plans` (الباقات)
- `id`, `name` (نص)، `price` (رقم)، `currency` (افتراضي EGP)
- `max_views_per_month` (رقم، NULL = غير محدود)
- `can_access_movies` (boolean)
- `features` (jsonb — قائمة مميزات نصية للعرض)
- `sort_order`, `is_active`, `created_at`

### 2. جدول `user_subscriptions` (اشتراكات الأعضاء)
- `id`, `user_id` (uuid)، `plan_id` (fk)
- `status` (active / expired / cancelled)
- `started_at`, `expires_at` (timestamp)
- `notes` (نص — للأدمن)

### 3. جدول `movie_views` (تتبّع المشاهدات)
- `id`, `user_id`, `movie_id`, `viewed_at`
- يُستخدم لحساب الاستهلاك الشهري

### 4. دوال مساعدة (SECURITY DEFINER)
- `get_user_active_plan(_user_id)` — يرجّع بيانات الباقة الحالية
- `get_monthly_views_count(_user_id)` — عدد المشاهدات في آخر 30 يوم
- `can_user_view_movie(_user_id)` — يرجّع true/false حسب الباقة والاستهلاك

### 5. RLS + GRANTs
- الباقات: قراءة عامة، كتابة للأدمن
- الاشتراكات: العضو يقرأ اشتراكه فقط، الأدمن يقرأ/يكتب الكل
- المشاهدات: العضو يقرأ/يكتب مشاهداته، الأدمن يقرأ الكل

## لوحة التحكم (Admin)

### تاب جديد "الباقات والاشتراكات" في `src/pages/Admin.tsx`
مكوّن جديد `src/components/admin/SubscriptionsManager.tsx` يحتوي على تبويبين فرعيين:

**أ. إدارة الباقات:**
- جدول بالباقات الثلاث مع تعديل الاسم/السعر/حد المشاهدات/المميزات
- تفعيل/تعطيل الباقة
- 3 باقات ابتدائية تُنشأ في seed data (الأدمن يعدّل الأسماء والأسعار)

**ب. اشتراكات الأعضاء:**
- جدول بكل الأعضاء (من `manage-users` الحالي) مع عمود إضافي: الباقة الحالية والحالة وتاريخ الانتهاء
- زر "تعيين باقة" لكل عضو: يفتح Dialog يختار فيه الباقة والمدة (شهر/3 شهور/سنة/مخصص)
- زر "إلغاء الاشتراك"
- عرض عدد المشاهدات الشهرية للعضو

## الواجهة (Frontend)

### 1. صفحة `/pricing` (جديدة)
- عرض الباقات الثلاث بشكل جذاب (بطاقات بالطراز الذهبي/السينمائي)
- زر "اشترك" يوجّه العضو لصفحة تواصل/واتساب مع الأدمن (لأن الدفع يدوي)
- رابط في Header وFooter

### 2. حماية صفحة تفاصيل الفيلم `MovieDetail.tsx`
- Hook جديد `useSubscription()` يرجّع الباقة الحالية والحالة
- لو العضو غير مشترك أو انتهى اشتراكه → عرض شاشة "اشترك للمشاهدة" مع زر يوجّه لصفحة الباقات
- لو المشاهدات وصلت للحد الأقصى → رسالة "استنفدت مشاهدات الشهر — رقّي باقتك"
- عند الدخول الناجح لصفحة الفيلم، يتم تسجيل مشاهدة في `movie_views`

### 3. صفحة "اشتراكي" (اختياري بسيط داخل بروفايل العضو)
- عرض الباقة الحالية، تاريخ الانتهاء، عدد المشاهدات المتبقية
